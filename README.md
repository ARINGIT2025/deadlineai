# DeadlineAI 🚀

> **AI-powered productivity companion built with Google Gemini.**

DeadlineAI is a smart task and schedule optimization assistant designed to help developers and students manage deadlines, prioritize workload, and conquer task paralysis using AI-driven breakdowns and automated reminders.

---

## ✨ Features

* **Smart Deadline Breakdown:** Automatically splits complex projects into actionable, bite-sized tasks.
* **Gemini Integration:** Powered by Google Gemini to analyze context, estimate task effort, and suggest priority scheduling.
* **Intelligent Reminders:** Keeps you on track with automated nudge notifications before deadlines hit.
* **Adaptive Scheduling:** Re-adjusts your daily plan dynamically as priorities or timelines shift.

---

## 🛠️ Tech Stack

* **Core Engine:** Python / Node.js
* **LLM Provider:** Google Gemini API
* **Frontend:** Web Interface / CLI
* **Database:** SQLite / PostgreSQL
